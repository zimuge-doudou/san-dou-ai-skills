# SKILL.md - PDF报告生成

## 技能信息
- **名称：** skill_pdf_report
- **优先级：** P1
- **版本：** 1.0.0

## 功能描述
生成纯文本格式的"伪PDF"报告，用ASCII艺术模拟PDF布局。支持三种报告模板：项目报告、设备清单、审计报告。

## 命令

### 生成报告
```bash
python pdf_report.py generate <data.json> [--template=项目报告|设备清单|审计报告]
```
- 从JSON文件读取数据，生成报告并保存到 `reports/` 目录
- 不指定 `--template` 时自动检测（根据JSON键名推断）
- 输出文件名格式：`{模板名}_{时间戳}.txt`

### 列出模板
```bash
python pdf_report.py templates
```
- 显示所有可用模板及其字段和章节结构

### 预览报告
```bash
python pdf_report.py preview <data.json> [--template=项目报告|设备清单|审计报告]
```
- 与 `generate` 相同，但直接输出到终端，不保存文件

## 模板说明

### 项目报告
JSON结构示例：
```json
{
  "项目名称": "XX项目",
  "负责人": "张三",
  "状态": "进行中",
  "进度": 65,
  "进度详情": [
    {"阶段": "需求分析", "状态": "已完成", "完成度": 100, "负责人": "李四"}
  ],
  "存在问题": ["资源不足"],
  "下一步计划": ["完成开发"]
}
```

### 设备清单
JSON结构示例：
```json
{
  "设备列表": [
    {"设备名称": "电脑", "型号": "ThinkPad", "数量": 10, "状态": "正常", "存放位置": "A区"}
  ]
}
```
也支持 `"设备"` 作为键名。

### 审计报告
JSON结构示例：
```json
{
  "审计范围": "权限系统",
  "检查项": [
    {"检查项": "密码策略", "检查结果": "通过", "风险等级": "低"}
  ],
  "整改建议": ["加强密码复杂度要求"]
}
```
也支持 `"检查详情"` 作为键名。

## 输出
- 报告保存在技能目录下的 `reports/` 文件夹
- 文件格式：纯文本 `.txt`，UTF-8编码
- 包含：标题、日期、数据表格（ASCII边框）、统计摘要、页脚

## 注意事项
- JSON文件必须是有效的UTF-8编码
- 自动检测仅根据JSON顶层键名推断，可能误判
- 建议始终指定 `--template` 以确保准确性
- 所有输出和日志均为中文
